# SMART BLOOD DONATION SYSTEM

## 1. PROJECT OVERVIEW

The Smart Blood Donation System is a web-based application developed to manage blood donors and blood requests efficiently during emergency situations. The system helps hospitals and patients quickly find suitable blood donors and reduces delays caused by manual record management.

---

## 2. OBJECTIVES

- Manage donor details digitally
- Reduce manual paperwork
- Search blood donors quickly
- Improve emergency blood support
- Send notifications to donors
- Provide user-friendly management system

---

## 3. TECHNOLOGIES USED

### Frontend
- HTML
- CSS
- Bootstrap
- React

### Backend
- Java
- Spring Boot

### Database
- MySQL

### Additional Technologies
- Emergency Notification System
- Email/SMS Alerts
- Blood Availability Search

---

## 4. MODULES

### Admin Module
- Manage donor details
- Manage blood requests
- Send notifications

### Donor Module
- Registration
- Login
- Update donor details

### Blood Request Module
- Search blood groups
- Request blood
- View donor details

### Notification Module
- Send emergency alerts
- Email/SMS notifications

---

## 5. TABLE LIST

| S.No | Table Name       | Description                          |
|------|------------------|--------------------------------------|
| 1    | Admin            | Stores admin details                 |
| 2    | User             | Stores login information             |
| 3    | Donor            | Stores donor details                 |
| 4    | Blood_Request    | Stores blood request information     |
| 5    | Notification     | Stores alert and notification data   |

---

## 6. EXPECTED OUTCOME

The system helps patients and hospitals quickly find blood donors during emergencies. It improves donor management, reduces manual work, and provides fast communication through notifications.

---

## 7. CONCLUSION

The Smart Blood Donation System provides an efficient digital solution for managing blood donors and emergency blood requests using modern web technologies.
